lofu extension settings

I. Your server

The address you reach lofu at: your Tailscale name (e.g. https://homebox.tail1234.ts.net) or a LAN address. Create a token on the server with bun run stack:token create browser. The toolbar shows a blue ✓ for saved pages. To check this, the extension reads page URLs and looks them up on this server; these checks never send page contents.

II. Repair pages the server can't read

Some sites refuse servers: logins (Zhihu), bot checks (Medium, V2EX). With auto-repair on, when you visit a page you've already saved that the server couldn't read, the extension sends the page as your browser shows it. Only those pages, nothing else. The repair list is checked locally; no extra URL lookups are needed for repair. Turning this on asks for access to all sites.

Needs your browser

    Nothing to repair. Every saved page is readable.

    III. Saving

    • Alt Shift S or the toolbar button saves the current page.
    • Right-click a page or link: Save to lofu.
    • Pages are sent as you see them, so articles behind your logins save in full.
